# Roles and Permissions - mobile-shoes-store

## 1. USER
Được phép:
- Xem sản phẩm
- Tìm kiếm
- Xem chi tiết sản phẩm
- Xem đánh giá
- Thêm vào giỏ hàng
- Đặt hàng
- Xem lịch sử đơn hàng
- Đánh giá sản phẩm
- Cập nhật hồ sơ cá nhân

Không được phép:
- Quản lý user
- Quản lý danh mục
- Quản lý sản phẩm
- Quản lý đơn hàng của người khác

## 2. ADMIN
Được phép:
- Quản lý user
- Quản lý danh mục
- Quản lý sản phẩm
- Quản lý đơn hàng
- Xem thống kê
- Có thể xem toàn bộ dữ liệu hệ thống

## 3. Gợi ý mở rộng role
- USER_ADMIN
- PRODUCT_ADMIN
- ORDER_ADMIN

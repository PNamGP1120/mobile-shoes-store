# Use Case - mobile-shoes-store

## 1. Actors
- Guest
- User
- Admin

## 2. Use cases của Guest
- Đăng ký
- Đăng nhập
- Xem sản phẩm
- Xem theo danh mục
- Tìm kiếm sản phẩm
- Xem chi tiết sản phẩm
- Xem đánh giá sản phẩm

## 3. Use cases của User
- Thêm vào giỏ hàng
- Cập nhật giỏ hàng
- Xóa khỏi giỏ hàng
- Đặt hàng
- Chọn phương thức thanh toán
- Xem lịch sử đơn hàng
- Xem chi tiết đơn hàng
- Đánh giá sản phẩm
- Đăng xuất

## 4. Use cases của Admin
- Quản lý user
- Quản lý danh mục
- Quản lý sản phẩm
- Quản lý đơn hàng
- Xem thống kê

## 5. Quan hệ kế thừa
- User kế thừa toàn bộ khả năng của Guest
- Admin có khu vực quản trị riêng
